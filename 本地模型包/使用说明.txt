通用翻译 - 本地模型翻译包
================================

内容:
- ollama\       Ollama 运行时（便携版，无需安装）
- models\       qwen2.5:0.5b、qwen2.5:1.5b、HY-MT-1.8B 三个翻译模型（已内置，离线可用）
- mods\         tongyongfanyi-1.4.0.jar（Fabric 版，只支持 Minecraft 26.3）
                ← 这个 jar 里**自带 Qwen2.5 0.5B 模型**（约 380MB），
                  换台新电脑只需装上它，首次进游戏会自动铺好模型，不用再拷贝 models 目录
                modmenu-21.0.0.jar（可选：装上后模组列表里会多一个"设置"按钮）
- 不带模型版\   tongyongfanyi-nomodel-1.4.0.jar（约 79KB，功能相同但不含模型；
                便携包 models\ 里已有 qwen2.5:0.5b 时用它更省空间，详见该目录 读我.txt）
- 1.8.9版\      Minecraft 1.8.9 Forge 版，两个 jar 二选一（该目录下有 读我.txt）：
                tongyongfanyi-forge189-1.0.0.jar（约 39KB，不带模型）
                tongyongfanyi-forge189-1.0.0-with-model.jar（约 368MB，自带模型）
- 配置示例\     一份现成的模组配置（模型=HY-MT-1.8B）
- 启动翻译服务.bat
- 停止翻译服务.bat

版本要求（Fabric 版 1.4.0）:
- Minecraft 26.3；Fabric Loader 0.19.3 及以上；Fabric API 0.161.0 及以上；Java 25。
- 和 26.2 的旧版不能混用：装的必须是 26.3 客户端，服务器版本无所谓（翻译只改本地显示）。

内置模型（1.3.0 起）:
- Fabric 版 jar 自带 Qwen2.5 0.5B，首次启动时会自动把它装到 Ollama 的模型目录
  （即上面"Ollama 程序路径 / 模型目录"指向的位置），装好后就是这个 jar 的默认模型。
- 安装只需一次（约 380MB 的本地拷贝，通常一两秒），设置页 -> 本地模型里能看到进度；
  装好后那一行会显示"已内置"。装在哪个目录取决于配置里的"模型目录"，
  没配置时依次回退到：便携包结构（ollama\ollama.exe 同级的 ..\models）→ 用户目录下的 .ollama\models。
- 也就是说：只要装了 26.3 的 Fabric 版，qwen2.5:0.5b 永远可用、永远不用联网下载。
  qwen2.5:1.5b 与 HY-MT-1.8B 不带在 jar 里，需要时在设置页点下载。

使用方法:
1. 把整个文件夹复制到任意电脑（路径可以含中文和空格）。
2. 双击"启动翻译服务.bat"，看到"模型服务已就绪"表示成功。
3. 把 mods\tongyongfanyi-1.4.0.jar 放进游戏 mods 目录（如已有旧版先删除）。
   建议把 mods\modmenu-21.0.0.jar 也一起放进去，这样可以在"模组列表 -> 通用翻译"
   里点"设置"按钮打开设置界面；不装 ModMenu 也行，进游戏后输入 /tyfy 同样能打开设置。
4. 启动游戏，在设置 -> 本地模型里选择模型：qwen2.5:0.5b（jar 自带，默认） / qwen2.5:1.5b / HY-MT-1.8B。
5. 也可以直接在游戏设置界面里启动/停止模型服务：本地模型页签里填好
   "Ollama 程序路径"（包内 ollama\ollama.exe）和"模型目录"（包内 models 文件夹），
   点"启动本地模型服务"即可，不玩时点"停止本地模型服务"。
6. 不玩时双击"停止翻译服务.bat"，或直接关闭启动脚本的窗口。

说明:
- qwen2.5:0.5b 最快、显存最小（约 0.5GB）；qwen2.5:1.5b 质量更好（约 1.5GB）。
- HY-MT-1.8B 是腾讯混元翻译模型（HY-MT2 1.8B，约 1.2GB），专为翻译优化，英文→中文效果更好。
- 没有独立显卡也能跑（自动用 CPU，速度会慢一些）。
- 如果 11434 端口被占用（例如本机还装了别的 Ollama），请先停掉那个再启动本服务。
- 翻译请求默认 10 秒超时（设置 -> 通用 -> 请求超时）。用云端接口可以调短一些，
  用 CPU 跑本地模型时建议放宽到 20~30 秒，否则容易超时失败。
- 翻译完全在本地进行，不上传任何内容，也不会修改发送给服务器的数据。

Minecraft 1.8.9 Forge 版（老版本/小游戏服务器）:
1. 版本必须是 1.8.9 的 Forge（如 11.15.1.2318）。启动一次游戏生成 mods 目录。
2. 到"1.8.9版"文件夹里**二选一**，只把选中的那一个放进游戏 mods 目录：
   - tongyongfanyi-forge189-1.0.0.jar             约 39KB   不带模型（模型已经在便携包 models 里，选它）
   - tongyongfanyi-forge189-1.0.0-with-model.jar  约 368MB  自带 Qwen2.5 0.5B，首次进游戏自动安装
   两个不能同时放；也不能和 tongyongfanyi-1.4.0.jar 同时放 —— 会因 modid 重复报错。
3. 模型服务启动方式与上面完全一样（双击"启动翻译服务.bat"，或用系统里装好的 Ollama）。
   用自带模型的那个 jar 时，需要在设置界面里填一次"模型目录"（便携包里的 models 文件夹）。
4. 1.8.9 版的配置文件名同样是 config\tongyongfanyi.json，
   可直接复制"配置示例"里的文件（.minecraft\config\ 下；PCL 则为
   .minecraft\versions\<版本>\config\）。
5. 进游戏后按 T 输入 /tyfy 打开设置界面；可以设置模型名、模型目录，以及安装内置模型。
6. 功能与新版一致：聊天、物品悬停提示、右上角计分板、顶部 Boss 栏文字
   都会翻译成中文，HUD 左上角会显示当前翻译后端/模型。
   注意：1.8.9 老版本客户端默认字体不支持中文时，请先在游戏设置里把
   "Unicode 字体"打开，否则中文会显示为方块。

新设备首次使用（模型未安装时）:
1. 先启动模型服务（双击"启动翻译服务.bat"，或在游戏设置里点"启动本地模型服务"）。
2. Qwen2.5 0.5B 由 jar 自带：进游戏后模组会自动把它装到"模型目录"，不需要任何操作，
   设置页 -> 本地模型里那一行会从"安装内置模型…"变成"已内置"。
   若显示失败，点那一行即可重试（按钮文字会变成"点此重试"）。
3. 打开游戏设置 -> 本地模型页，界面会列出三个模型并显示"已安装/未安装"。
4. 没有内置的模型（qwen2.5:1.5b、HY-MT-1.8B）才会显示下载按钮，点"下载"后等待进度到 100%。
   下载需要联网，模型会保存到本包的 models 文件夹，之后离线也能用。
   下载会自动选择源：官方源可达就走官方，不可达或失败时自动切换
   HuggingFace 国内镜像 (hf-mirror.com)，无需手动配置。
   注意：HY-MT-1.8B 的官方 Ollama 打包带专用提示词模板，国内镜像打包会损坏
   模板导致翻译乱码，因此 HY-MT-1.8B 只走官方源；若官方源不可达，请先开启
   加速器（v2rayN/Clash 等）再下载。
   如果开了加速器（v2rayN/Clash 等），游戏内"启动本地模型服务"会自动检测本地代理
   并让 Ollama 走代理下载，不需要额外设置。

模型选择:
- 本地模型设置页的"模型"选择器里有 qwen2.5:0.5b、qwen2.5:1.5b、HY-MT-1.8B 三项。
- 选择任意一项即可切换翻译模型，改动立即生效。

在另一台电脑上使用（重要）:
1. 把整个"本地模型包"文件夹（或解压 zip）复制过去，路径可以含中文和空格。
2. 双击"启动翻译服务.bat"，看到"Model service is ready"表示模型服务已就绪。
3. 把 mods\tongyongfanyi-1.4.0.jar 放进那台电脑的游戏 mods 目录（旧版先删掉）。
   1.4.0 的 jar 自带 Qwen2.5 0.5B，**新电脑上不需要再拷贝本包的 models 目录**：
   装上 jar、启动 Ollama 后，模组首次进入游戏会自动把模型装好。
4. 首次使用时，把"配置示例\tongyongfanyi.json"复制到游戏的 config 文件夹覆盖
   （游戏目录一般是 .minecraft\config\，PCL 启动器则是
   .minecraft\versions\<版本>\config\），这样进游戏就是"本地模型 + HY-MT-1.8B"，
   三个模型都已内置，不需要联网下载。
   不复制配置也行：进游戏后输入 /tyfy 打开设置 -> 本地模型设置，模型选 HY-MT-1.8B 即可。
5. 建议在游戏设置 -> 通用里开启"翻译界面文字(模组界面)"，未汉化的英文模组界面也会被翻译。
6. 每台电脑只需首次配置一次，之后模型都是离线本地运行。
