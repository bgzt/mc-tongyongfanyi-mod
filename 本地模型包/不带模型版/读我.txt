通用翻译 · 不带模型版（Minecraft 26.3 / Fabric）
================================================

这个文件夹里是**不含模型**的 jar：

  tongyongfanyi-nomodel-1.4.0.jar   约 79KB

和上一级 mods\ 目录里的 tongyongfanyi-1.4.0.jar（约 380MB，自带 Qwen2.5 0.5B）
功能完全一样，只是不把模型打包进 jar。

该用哪一个？
- 便携包里的 models\ 目录已经带了 qwen2.5:0.5b —— 用**这个**小 jar 就够了，
  省 380MB 空间，启动也不需要解包安装内置模型。
- 换到一台新电脑、不想拷贝 models\ 目录 —— 用上一级 mods\ 里自带模型的那个 jar。

注意
----
1. 两个 jar 的 modid 相同（tongyongfanyi），**只能选一个**放进游戏 mods 目录，
   同时放会因 modid 重复导致游戏启动失败。
2. 也不要和 1.8.9版\ 里的 Forge jar 同时放（同样会 modid 冲突）。
3. 版本要求：Minecraft 26.3 + Fabric Loader 0.20.1 及以上 + Fabric API 0.165.0 及以上 + Java 25。
4. 用这个小 jar 时，模型目录要指向便携包的 models\ 文件夹
   （设置 -> 本地模型 -> 模型目录；没配过会依次回退到 ollama\ollama.exe 同级的 ..\models
   和用户目录下的 .ollama\models）。
